> **What survives the night.** Whatever the agent writes here is read at the start
> of the next incident, so a bad line costs twice.

Write one line for whoever picks up the next incident, and call `remember` with
it.

A line earns its place if it would change somebody's first move next time.
Write the lesson, not the story.

- **Good:** templates must ship with every partial they reference; a missing
  one breaks order creation after payment succeeds.
- **Bad:** we had an incident on the 25th and rolled back.

One line. If nothing this night taught you that, say so rather than padding.
